## About

This site is where I host and showcase personal coding projects, built while studying my Bachelor of Information Technology at Griffith University and continuing since. It's a static HTML/CSS site deployed via GitHub Pages.

## Projects

### Highway To Hell
*JavaScript · p5.js — Completed January 2020*

A top-down scrolling game where the player drives along a highway toward hell, dodging fireballs while managing a draining fuel gauge. Collect fuel and repair pickups to survive as long as possible.

Built in about a week using the p5.js library. High scores are now saved to a hosted database, so scores persist across sessions.

**[Play it here](https://matthew-f-reid.github.io/myWebsite/highway_to_hell/index.html)**

### Campus Escape
*Unity · C# — Completed September 2019*

A first-person survival game set in a library on campus. The player navigates around zombies, collects ammo pickups, and must find every key to unlock the exit.

This build isn't currently published — happy to walk through the project or provide a demo on request.

## Tech Stack

- HTML / CSS for the site itself
- JavaScript + [p5.js](https://p5js.org/) for Highway To Hell, with a hosted database for persistent high scores
- Unity + C# for Campus Escape
- Hosted via GitHub Pages
